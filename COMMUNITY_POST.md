# Post Title

Free Chrome extension: check what your AI coder changed without asking

# Post Copy

"Done" isn't much of a QA process.

After watching a coding agent declare a build finished before it actually worked, I wanted a simple way to check the SEO bits before and after an edit.

So I built SEO Change Guard. Free, open source, runs locally in Chrome.

Open a page and capture a baseline before you touch it. Make your changes, reload that same page, then compare.

It shows changes to the title, meta descriptions, canonicals, robots directives and H1-H3 headings. It also picks up removed internal links and added or removed external links, with before/after viewport screenshots and an HTML report you can keep or share.

Useful when you're letting AI edit a site, changing templates or handing work back to a developer. The page looking fine doesn't tell you whether its canonical disappeared.

No API keys, account or subscription. The extension doesn't upload your captures.

It's a manual, one-page check, not a crawler or a guarantee that Google can index the page. You need to capture the baseline before the edit.

Download: https://github.com/Aaron-Agius/change-guard/releases/latest

Unzip it, open chrome://extensions, enable Developer mode and Load unpacked. Select the seo-change-guard folder. Desktop Chrome/Chromium.
